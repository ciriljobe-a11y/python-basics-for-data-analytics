# Python Basics for Data Analytics | Practice 1

## Project Overview

This repository contains beginner-level Python programming exercises developed as part of my Python learning journey, with a focus on building foundational programming knowledge for data analytics.

The exercises cover Python fundamentals, data structures, conditional logic, loops, and basic calculations using practical examples.

## Topics Covered

### 1. Python Fundamentals
- Print statements
- Basic arithmetic operations
- Variables and assigning values
- Strings and numeric values
- Checking data types using `type()`

### 2. Python Data Structures
- Lists
- Accessing list elements
- Adding elements using `append()`
- Updating list values
- Tuples
- Sets
- Dictionaries
- Accessing and updating dictionary values

### 3. Conditional Statements
- `if` statements
- `if-else` statements
- `if-elif-else` statements
- Basic eligibility checking
- Student grade evaluation

### 4. Loops
- `for` loops
- `range()` function
- Iterating through lists

### 5. Basic Data Analytics Calculations
- Basic sales calculations
- Adding sales values
- Calculating total sales
